# Spark Practice

A hands-on project for learning Apache Spark through practical exercises. The notebooks explore Spark concepts and APIs by working through examples.

## Project contents

- [`notebooks/`](./notebooks/) — Spark exercise notebooks.
- [`sample-data/northwind/`](./sample-data/northwind/) — CSV files used in data exercises.

## Getting started

1. Open a notebook from `notebooks/` in VS Code or Jupyter.
2. Select a Python environment with the required PySpark dependencies.
3. Configure and start the Spark environment required by the notebook. Some exercises use Spark Connect; check the notebook setup and connection settings before running its cells.
4. Work through the notebook cells and experiment with the examples.

The notebooks may rely on different Spark configurations or data locations, so follow the setup notes in each notebook.
